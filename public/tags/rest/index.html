REST API và Kiến trúc Client-Server

REST API và Kiến trúc Client-Server REST (Representational State Transfer) là kiến trúc phổ biến nhất để xây dựng API cho ứng dụng web. Bài viết này sẽ giải thích REST API và mô hình Client-Server một cách chi tiết. Kiến trúc Client-Server Mô hình cơ bản ┌──────────────┐ HTTP Request ┌──────────────┐ │ │ ─────────────────────────────►│ │ │ CLIENT │ │ SERVER │ │ │◄───────────────────────────── │ │ └──────────────┘ HTTP Response └──────────────┘ (Browser, (API, Mobile App, Database, Desktop App) Business Logic) Đặc điểm Client: Gửi request, hiển thị dữ liệu cho user Server: Xử lý logic, lưu trữ dữ liệu, trả response Stateless: Server không lưu trạng thái client giữa các request Separation of Concerns: Tách biệt UI và logic REST là gì?
